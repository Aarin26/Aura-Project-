# Production Engine Handoff Note — SynCom Bottle

## Universal Blender / Unity / Unreal Import Instructions

### Blender (Any Version):
1. Open Blender.
2. Click `File > Import > glTF 2.0 (.glb/.gltf)` (or `File > Import > Wavefront (.obj)`).
3. Select `C:\Users\aarin\OneDrive\Desktop\Vuforia\Aura-Project-\outputs\phase_7_export\asset.glb`.
4. Press `Z` -> Select **Material Preview** to view the full textured 3D bottle model.

### Unity Engine:
1. Drag `asset.glb` directly into the Unity `Assets/` project window.
2. Drag the imported asset into your scene.

### Unreal Engine 5:
1. Click `Import` in the Content Browser.
2. Select `asset.glb` or `asset.obj` and import.
